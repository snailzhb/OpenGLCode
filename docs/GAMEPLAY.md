# GameEigen Voxel — 玩法说明

面向当前 `OpenGLCode` 体素演示的**操作、模式与轻量目标**。实现细节以 `src/app/VoxelApplication.cpp` 为准。

> 引擎分层（物理、光照、Game API、场景扩建）见 [ENGINE.md](ENGINE.md)。

---

## 1. 核心玩法概览

在程序化生成的村落与地形中**自由移动**，用**破坏 / 放置方块**改造环境，通过**地标探索**与**交互**积累探索分数。昼夜与天空、水面折射、路灯点光等为氛围系统，不构成胜负条件。

---

## 2. 操作一览

| 输入 | 作用 |
|------|------|
| **W A S D** | 水平移动（行走模式沿地面；飞行模式沿视角） |
| **空格** | 行走：在地面时跳跃；在水中：上浮；飞行：上升 |
| **Shift** | 行走：在地面按住可略提高移动速度；飞行：下降 |
| **鼠标移动** | 仅在鼠标捕获（Tab 后）下转动视角 |
| **鼠标左键** | 破坏视线内方块（约 10 格内，需捕获鼠标） |
| **鼠标右键** | 在瞄准面的邻格放置当前快捷栏方块（空气 / 水 / 玻璃可被替换；不可与身体碰撞盒重叠） |
| **滚轮** | 切换快捷栏槽位（需捕获鼠标） |
| **1–9、0** | 直接选中第 1–10 号快捷栏槽 |
| **Tab** | 切换鼠标捕获 / 释放（释放后可操作桌面，此时不转视角、不挖矿） |
| **F** | **行走模式** ↔ **飞行模式**（飞行：无重力与碰撞，空格上、Shift 下） |
| **E** | **交互**（见下文「交互与路灯」） |
| **G** | **吸取方块**：将十字准星命中的实体方块写入**当前槽位**并设为手持 |
| **H** | 传送回村落锚点（出生广场附近），并重置竖直速度 |
| **Esc** | 关闭窗口 |
| **F11** | 切换无边框最大化（模拟全屏） |
| **鼠标中键** | 同 F11，切换无边框最大化 |

### 快捷栏默认顺序（槽 1–10）

草、土、石、沙、木、**圆石（默认选中）**、玻璃、浅玻璃、深玻璃、暖色路灯。

### 额外快捷键

- **F1**：选中第 10 槽（与 `0` 相同）。
- **F2**：将第 10 槽设为**青色路灯**并选中。
- **F3**：将第 10 槽设为**品红路灯**并选中。

## 3. 移动与物理

### 行走模式（默认）

- 重力与简易 AABB 碰撞：脚高约 `1.62` 方块，身体宽约 `0.56` 方块。
- 落地后竖直速度清零；可走台阶式地形。
- **水中**：移动变慢，空格可上浮，有阻尼感；HUD 会显示简短水中提示条。

### 飞行模式（F）

- 无碰撞、无重力；**W A S D** 沿视角水平分量移动；**空格**上升、**Shift**下降。

---

## 4. 建造与瞄准

- **准星**：捕获鼠标时屏幕中心十字线。
- **方块描边**：可合法射线命中实体方块时，该方块显示高亮线框（深度可见，便于判断前后关系）。
- **放置距离**：与相机距离约小于 9 格的面外邻格才可放置（与射线最大距离配合，避免过远放块）。
- **可替换类型**：空气、水、任意玻璃族方块上可直接覆盖放置。

---

## 5. 交互与路灯（E）

优先级大致如下（实现上先判定旗帜，再判定瞄准方块）。

### 村落旗帜

- 在旗帜附近、大致朝向旗帜时按 **E**，会触发一句氛围提示，并获得少量探索分数。

### 瞄准方块上的交互

| 方块类型 | 按 E（默认） | 按 E 且按住 **Shift** |
|----------|----------------|------------------------|
| 任意路灯族 | 在暖 / 白 / 青 / 品红之间**循环换色** | 将该格替换为**木柱**（“关灯”） |
| 水 | 氛围文本 | 同左 |
| 干草顶、铺路石、陶瓦顶等 | 氛围文本 | 同左 |
| **木柱** | 若柱顶两格为空气，在柱顶放置**暖色路灯**（“重新点灯”）；否则仅描述木柱 | 同左 |
| 其他实体 | 通用「检视」类提示（显示方块英文名缩写） | 同左 |

## 6. 探索：地标与分数

世界中设有 **4 个地标触发点**（进入约 10 格范围内即算「发现」一次，不可重复）：

1. **Village Square** — 村落广场附近  
2. **Wooden Bridge** — 木桥一侧（相对出生锚点的西北一带）  
3. **Stone Monument** — 与导入的 `h_model.voxdat` 纪念碑区域相关（若未导入文件，该区域可能无对应建筑，但触发点仍存在）  
4. **Chimney Smoke** — 烟囱/村落一侧的参考点  

- **发现地标**：每条 +3 探索分，并弹出提示。  
- **与旗帜互动**：每次 +1 探索分。  

窗口标题栏会周期性刷新：**当前手持方块名**、**已发现地标数 / 4**、**探索总分**、**Walk / Fly** 模式，以及当前 toast 文案摘要。

---

## 7. 界面与提示

- **底部快捷栏**：彩色块表示槽内方块类型；金色描边为当前选中槽。  
- **E 提示角标**：当准星附近存在可交互目标（路灯、部分装饰方块、水或旗帜方向判定）时，一角会显示呼吸式高亮。  
- **Toast**：屏幕上方条带 + 标题栏文字，用于欢迎语、发现地标、吸取方块、交互结果等。

---

## 8. 世界与性能相关（影响玩法体验）

- **区块流式加载**：随相机所在 chunk 更新周围世界；走远后远处区块会被卸载以控制内存（已放置的改造在卸载后会丢失，仅保留仍在加载范围内的 chunk）。  
- **开局暖机**：前几秒会略提高每帧创建区块预算，减少「装饰慢慢长出来」的感觉。

## 9. 建议玩法流程（自设目标）

1. **Tab** 捕获鼠标，熟悉 **行走 / F 飞行** 切换。  
2. 沿出生朝向寻找**木桥**与**广场**，用 **E** 与旗帜、路灯、水面互动。  
3. 用 **G** 从建筑上吸取材质，用 **左键 / 右键** 做小改造或搭桥。  
4. 寻找四处地标，把标题栏 **4/4 探索** 打满；若迷路按 **H** 回村。  

本作无存档、无敌人、无资源数值；乐趣来自**观光、轻量建造与收集式探索**。
